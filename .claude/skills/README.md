# Projekt-Skills

Diese Skills lädt Claude Code automatisch, sobald das Repo geöffnet wird.

| Skill | Zweck | Quelle |
|---|---|---|
| `web-design-guidelines` | UI-Code gegen die Web Interface Guidelines prüfen | vercel-labs/agent-skills (MIT) |
| `awesome-design` | 84 echte Design-Systeme als DESIGN.md-Referenz | VoltAgent/awesome-design-md (MIT) |
| `image-to-code` | Screenshot/Mockup in Streamlit-Code umsetzen | eigener Skill |
| `playwright-cli` | Browser steuern, Screenshots, UI testen | microsoft/playwright-cli (Apache-2.0) |

## Voraussetzung für `playwright-cli`

Das Kommandozeilen-Tool muss installiert sein:

```bash
npm install -g @playwright/cli@latest
```
